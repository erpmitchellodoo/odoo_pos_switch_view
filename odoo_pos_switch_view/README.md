# POS Switch View — Odoo 17

Grid and List buttons change the POS product layout. List displays one product per row. Browser storage remembers the choice per POS configuration.

Install this folder in your Odoo 17 addons path, restart Odoo, update the Apps List and install POS Switch View. Reload the POS.

The ProductsWidget extension preserves native product selection, search, categories, images and product prices and information controls. No external service is required.

Test desktop/mobile layouts, images disabled, product selection, category/search filtering, reload persistence and unavailable localStorage before publishing. Odoo 19 reference previews are labeled in the description.
